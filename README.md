# Sistema de Gestión para el Centro de Salud Pirapó Puerto

## 📌 Objetivo del Proyecto
Desarrollar un prototipo de sistema web para la optimización del agendamiento de citas médicas y la administración de registros clínicos en el Centro de Salud de Pirapó Puerto, facilitando la atención a los pacientes y el control administrativo.

## 🛠️ Entorno de Programación y Tecnologías
* **Lenguaje:** PHP 8.x / JavaScript
* **Framework:** Laravel 12 / Bootstrap 5 (AdminLTE)
* **Gestor de Base de Datos:** MySQL
* **Entorno Local:** XAMPP / Docker Desktop (con WSL 2)
* **Editor de Código:** Visual Studio Code
* **Control de Versiones:** Git y GitHub
